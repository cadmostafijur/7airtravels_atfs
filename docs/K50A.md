# K50A integration notes

Target: **ZKTeco K50A** fingerprint attendance terminal.

## Network

```
K50A -- Ethernet -- Office router/LAN -- ATFS server
```

- The K50A is **not** assumed to have Wi-Fi or 4G.
- Default ZKTeco standalone port is often **4370**. This system never hardcodes that in the UI; IP and port are configurable.
- Do not publish the device TCP port on the public internet.
- Remote access: VPN, private 4G router, or a reverse tunnel to the **application**, not to the terminal.

## Adapter isolation

All K50A protocol code is in `src/lib/devices/k50a-adapter.ts`.

Candidate library: `node-zklib` (ZK binary protocol over TCP, UDP fallback).

**Physical K50A firmware has not been verified in this repository.** If handshake fails after a successful TCP probe, replace only the adapter.

## Implemented against the adapter interface

- TCP probe
- connect / disconnect
- getDeviceInfo (user/log counts from `CMD_GET_FREE_SIZES`)
- getUsers
- getAttendanceLogs
- getDeviceStatus
- clearAttendanceLogs (SUPER_ADMIN + explicit confirmation)

## Not invented

- Undocumented K50A HTTP/ADMS APIs
- Fingerprint template storage in PostgreSQL
- `createUser` / `updateUser` / `deleteUser` write payloads for the physical device

Enroll users on the terminal. Store `deviceUserId` on the employee record.

## Offline behaviour

The K50A stores punches locally. The sync worker downloads the full log and inserts only new `(deviceId, deviceUserId, timestamp)` rows. Repeating sync cannot create duplicates.

## Probe

```bash
npx tsx scripts/device-probe.ts --ip 192.168.1.201 --port 4370
```
